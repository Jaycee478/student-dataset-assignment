# Assignment Two: Student Dataset Creation

## Description
This project uses Python to create a fictional student dataset containing 20 student records.

## Required dataset information
1. Student ID
2. Department
3. Level
4. Attendance Percentage
5. Average Examination Score

## Project files
- `student_dataset.py` — Python program that generates the dataset.
- `student_dataset.csv` — CSV file containing the 20 fictional student records.
- `README.md` — Project description and instructions.

## How to run the program
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run `python student_dataset.py`.

The program will create `student_dataset.csv` in the current folder.

## Note
All student names/IDs and academic records are fictional and are used only for this assignment.
